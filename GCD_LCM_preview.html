  4. So $x=8\cdot13=104,\ y=8\cdot12=96$.
With $m=\gcd=x-y$ and $x=mx_1,y=my_1$: $m^2x_1y_1=9984=2^8\cdot3\cdot13$ and $x_1-y_1=1$. The case $m=8$ gives $x_1=13,y_1=12$, hence the integers are $\mathbf{104}$ and $\mathbf{96}$.

Q15 HARD 📝 Proof · reveal solution
For every positive integer $n$ let $T_n=2^{2^{\,n}}+1$ (the Fermat numbers). Show that if $m\neq n$ then $T_m$ and $T_n$ are relatively prime.
💡 Hint

Nudge: Use the identity $T_0T_1\cdots T_{k-1}=T_k-2$.

Go deeper: A common divisor of $T_m,T_n$ would divide $2$, but each $T_n$ is odd.

🔎 Reveal solution
  1. Show $\prod_{i=0}^{k-1}T_i=T_k-2$ by induction.
  2. If $m<n$ then $T_m\mid T_n-2$, so any common divisor $d$ of $T_m,T_n$ divides $2$.
  3. Each $T_n$ is odd, so $d=1$. Hence $\gcd(T_m,T_n)=1$.
Using $T_0\cdots T_{k-1}=T_k-2$: for $m<n$, $T_m\mid T_n-2$, so $\gcd(T_m,T_n)\mid 2$; as $T_n$ is odd, the gcd is $1$.
